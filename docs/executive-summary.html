2 · What “highest dollar amount” can honestly mean

Kalshi exposes several different size quantities, and they are not interchangeable:

FieldOfficial meaningUsable as a “biggest market” ranking?
volume_fpContracts traded on the marketYes — a count, so it ignores price
volume_24h_fpContracts traded in the last 24 hoursYes, and it is the better measure of “live right now”
open_interest_fpContracts held, not nettedYes — measures exposure rather than activity
notional_value_dollars“The total value of a single contract at settlement in dollars”No. It is a per-contract settlement value, not a traded volume

Sources: Get Markets. This project shows the labelled estimate volume_fp × last_price_dollars and, separately, raw contracts and open interest, so you can re-rank on the axis you actually care about.

3 · The four things a decision-maker should know

Demo ≠ real

Kalshi states demo prices “may not be reflective of those in real markets”. Every ranking here is a demo ranking. Source

There is no anonymous real-time feed

Every WebSocket session is key-authenticated, even for public channels, so a static site cannot stream ticks. Source

Fees decide marginal strategies

The general taker fee is 0.07 × C × P × (1−P), about 2¢ per contract at 50¢ — roughly 4% of stake, and it is not yet in the performance numbers. Source

One step needs you

A demo account and API key must be created by a person. That is the only blocker to real demo performance reporting. Source

4 · How the numbers stay honest

A scheduled, credential-free collector reads public demo endpoints and commits a timestamped snapshot. A validator refuses a snapshot that invents a price, coerces a result to yes/no, or lacks provenance. The site renders that snapshot statically, so every figure is tied to one fetch time and one query URL. The pipeline is described on the home page, the rules on Verification, and everything that failed or is unresolved on Flagged for Review.
