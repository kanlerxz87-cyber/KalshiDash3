Portfolio and trade tracking

Status: blocked. Portfolio, balance, positions, fills and order placement all require authenticated requests. The sandbox has no Kalshi credentials, and this session cannot create a demo account or API key. Nothing on this page has been measured. Tracked by U1 and question Q4.

What is needed from you (once)

  1. Create a Kalshi demo account. The step-by-step help article is linked from the Kalshi demo docs: Creating and using a demo account (source: demo environment docs, opened).
  2. Generate a demo API key. Demo keys only work against demo endpoints (API environments, opened).
  3. Give the key to the agent through a secure channel, never in the repo or in chat. Then the portfolio sync and trade-tracking sections can be built.
