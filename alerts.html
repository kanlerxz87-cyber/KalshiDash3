Live swing alerts

Every contract-price swing of ≥ $0.10 in either direction, in the five tracked topics, turned into a scrolling alert feed. All events shows every qualifying swing; High ROI shows the subset the project's model rates as a high return on the moving side. Alerts are computed from the committed data/live/price_history.json observations, so each one is traceable to a fetch time and a query URL. This is snapshot polling, not a WebSocket stream: Kalshi WebSocket sessions require an API key (source).

Cause of a jump is left blank, on purpose. Kalshi publishes no official feed of why a price moved. Each alert therefore links the verifiable official Kalshi market and event API URLs and leaves the cause blank and flagged. Nothing is inferred and no external news link is invented (F-14). The high-ROI score is a project-local heuristic, not a Kalshi field (F-15).
