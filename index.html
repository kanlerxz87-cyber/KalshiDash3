KalshiDash3 — Executive Summary

Purpose. Collect, organize, and analyze live Kalshi demo trade-api v2 events, focused on five topics: gas prices, elections, culture, crypto, and golf.

Surface. Official recommended demo endpoint: https://external-api.demo.kalshi.co/trade-api/v2 (also supported: https://demo-api.kalshi.co/trade-api/v2). WebSocket API: wss://external-api-ws.demo.kalshi.co/trade-api/ws/v2 (also: wss://demo-api.kalshi.co/trade-api/ws/v2).

Scope. Track live events until they resolve (resolution: Yes or No); track portfolio performance using the Kalshi demo account; analyze trade results, categorize trades, and build strategies by trade type; view price movements on a time graph (X axis = time in seconds/minutes/hours; Y axis = current contract price); view current liquidity (contracts available at a given price).

Decision support. A suggestions section lets someone review suggestions and choose the best path before implementing changes. A questions/information/answers section lists what must be addressed before any decision can be reasonably made, plus suggestions to discover missing information.

Verification status. This sandbox cannot reach the Kalshi hosts (outbound network is limited to GitHub hosts and package registries). Every value on this site is therefore blank and flagged unverified until confirmed against an official Kalshi source. No values are inferred or filled in. See Flagged for Review for the full list.

Dashboard features

  • Price movement graph — current contract price (Y axis) over time (X axis), selectable seconds/minutes/hours window, with current liquidity (contracts available at a given price).
  • Portfolio performance — Kalshi demo account tracking, trade results analysis, categorization.
  • Trade categorization & strategies — strategies based on type of trade.
  • Suggestions — review suggestions and choose the best path before implementing changes.
  • Questions / information / answers — preconditions for decisions and missing-information discovery.

How to read this site

  • — means the value could not be confirmed from an official source and is intentionally left blank.
  • unverified means the row is flagged for review against an official Kalshi source.
  • Every table row carries a source link to an official Kalshi site for manual review.
  • There is no manual input required to use the site; all entries, findings, and analysis are pre-populated as verified/unverified.
